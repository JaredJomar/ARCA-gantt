ARCA - Gantt clásico

Datos en vivo desde los issues de GitHub (repo JaredJomar/ARCA). Arrastra barras para cambiar fechas, estira para cambiar duración, arrastra entre barras para crear dependencias. Todo se guarda en el issue. Arrastra el borde derecho de un encabezado de columna para ensancharla.

El token se guarda en este dispositivo, nunca en un servidor. Para ver basta uno de lectura; para editar necesitas uno con escritura.
¿Cómo creo el token con escritura?
En GitHub: Settings, Developer settings, Personal access tokens, Tokens (classic), Generate new token (classic). Marca el scope repo y ponle expiración corta. El token clásico es el que funciona para colaboradores: el fine-grained no incluye repos de otra cuenta personal. Pégalo arriba y pulsa Cargar Gantt. Se puede revocar en un clic si se expone.

Carga por persona

Una tarea con varios asignados cuenta para cada uno. Los días son días laborables (lunes a viernes, sin los feriados de la lista) de cada tarea abierta o cerrada. "Máx. simult." es la mayor cantidad de tareas abiertas de esa persona el mismo día.
